# 🚀 TO-DO LIST KELompok 3

### Aplikasi Web untuk Mengelola dan Meningkatkan Produktivitas

---

## 📌 Tentang Aplikasi

**To-Do List** merupakan aplikasi berbasis web sederhana yang dirancang untuk membantu pengguna dalam mencatat, mengatur, dan mengelola aktivitas atau pekerjaan sehari-hari.

Aplikasi ini memungkinkan pengguna untuk menambahkan daftar tugas, menandai tugas yang telah diselesaikan, menghapus tugas yang tidak diperlukan, serta melihat jumlah seluruh tugas yang tersedia.

Proyek ini dikembangkan sebagai bagian dari praktikum mata kuliah **Rekayasa Perangkat Lunak (RPL)** dengan menerapkan metode pengembangan perangkat lunak **Agile menggunakan kerangka kerja Scrum**, serta memanfaatkan Git dan GitHub sebagai media kolaborasi antaranggota tim.

## 🎯 Tujuan Aplikasi

1. Memudahkan pengguna dalam mencatat aktivitas dan pekerjaan.
2. Membantu pengguna mengelola daftar tugas secara terstruktur.
3. Mempermudah pemantauan tugas yang sudah dan belum diselesaikan.
4. Meningkatkan efisiensi dalam mengatur kegiatan sehari-hari.
5. Menerapkan konsep pengembangan perangkat lunak secara kolaboratif.

## ✨ Fitur Utama

| No. | Fitur | Deskripsi |
|---|---|---|
| 1 | Tambah Tugas | Menambahkan tugas baru ke dalam daftar. |
| 2 | Tandai Selesai | Menandai tugas yang telah selesai dengan teks tercoret. |
| 3 | Hapus Tugas | Menghapus tugas dengan klik dua kali. |
| 4 | Hitung Tugas | Menampilkan jumlah tugas yang terdapat dalam daftar. |
| 5 | Tampilan Sederhana | Menyediakan antarmuka yang rapi dan mudah digunakan. |

## 🛠️ Teknologi yang Digunakan

Proyek ini dibangun menggunakan beberapa teknologi berikut:

- **HTML5** — Membuat struktur halaman aplikasi.

## 🚀 Cara Menjalankan Aplikasi

Ikuti langkah-langkah berikut untuk menjalankan aplikasi:

1. Download atau clone repository proyek dari GitHub.
2. Buka folder `todo_kelompok_3`.
3. Cari file `index.html`.
4. Klik dua kali file `index.html` atau buka menggunakan browser.
5. Aplikasi siap digunakan.

**Catatan:** Aplikasi dapat dijalankan langsung melalui browser tanpa perlu menginstal framework tambahan.

## 🔄 Metode Pengembangan

Pengembangan aplikasi ini menggunakan metode **Agile dengan kerangka kerja Scrum**.

Tahapan yang dilakukan meliputi:

1. **Sprint Planning** — Menentukan kebutuhan, prioritas, dan pembagian tugas.
2. **Sprint Development** — Setiap anggota mengembangkan fitur sesuai tanggung jawabnya.
3. **Daily Scrum** — Membahas perkembangan pekerjaan dan kendala.
4. **Sprint Review** — Memeriksa dan mengevaluasi hasil pengembangan aplikasi.
5. **Sprint Retrospective** — Mengevaluasi proses kerja untuk perbaikan berikutnya.

Kolaborasi kode dilakukan menggunakan Git dan GitHub melalui branch, commit, pull request, code review, dan merge.
